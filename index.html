Where to start

Twelve steps is a lot for a small project. If you are starting out, this order pays off fastest:

1. Validate the outputA Pydantic model and one re-ask. No new infrastructure, and it fixes most broken JSON.
2. Log every callPrompt version, model, tokens, latency. A few lines that make every incident debuggable.
3. Add 20 eval casesReal inputs with expected outputs, run in CI. Now every prompt change has a score.
